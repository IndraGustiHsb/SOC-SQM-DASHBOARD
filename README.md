# SOC-SQM-DASHBOARD

Dashboard SQM/NOC berbasis static HTML, CSS, JavaScript dan `data/raw_data.csv`.

## Data
- 130,936 records
- 14 columns
- Period tersedia: 1 Oct 2026 00:00 sampai 3 Oct 2026 09:45
- Region: 16
- Circle: 492
- Branch: 108
- Kabupaten: 548

## Traffic
Source column `Total Traffic(Byte)` ditampilkan sebagai TB decimal dengan pembagian 1,000,000,000,000.

## Jalankan
Bisa dipublish langsung ke GitHub Pages. Karena browser membatasi fetch file lokal, untuk test lokal gunakan server sederhana, misalnya VS Code Live Server.
